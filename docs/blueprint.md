# **App Name**: Smart Guest

## Core Features:

- User Authentication: Secure login via Email, Google, Apple ID, with guest mode.
- Profile Creation: Collect user preferences (language, trip type, eco-sensitivity) for personalized service.
- Personalized Dashboard: Display dynamic welcome message and EcoScore indicator.
- AI-Powered Smart Concierge: Simulated AI assistant for answering queries and providing personalized recommendations. This assistant is a tool, making use of the user profile and eco-sensitivity.
- Eco Manager: Real-time visualization of environmental impact with an overall eco-score and badges.
- Sustainable Services & Reservations: Listing of services with descriptions, prices, eco-labels, and a 'Durable only' filter.
- Local Eco-Friendly Experience Recommendations: Recommends local sustainable activities based on geolocation, weather, and user preferences.

## Style Guidelines:

- Primary color: Deep blue (#0057B8), evoking trust and innovation.
- Background color: Light blue (#F3F4F6), for a clean and modern feel.
- Accent color: Green (#4CAF50), symbolizing sustainability and eco-friendliness.
- Body and headline font: 'Poppins' sans-serif for a modern, readable interface.
- Homogeneous vector icons representing services, eco-indicators, and user actions.
- Card-based design for presenting information in a structured, digestible format.
- Subtle lateral animations for smooth transitions between modules.
